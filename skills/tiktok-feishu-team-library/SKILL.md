# TikTok 飞书团队素材库

将关键词任务变成经过校验的视频文件和可在线播放下载的飞书附件。默认不用 Gemini 或 Apify，不承诺第三方服务永久免费。当前执行器是 Windows 单机，支持巴西葡语；墨西哥需要另加语言和地区策略。

## 配置或迁移

阅读 [references/setup.md](references/setup.md)，安装依赖并创建私有配置。先检查目标环境已有的飞书表结构和按钮，按名称匹配字段并获取真实 ID；不要重复创建表。配置必须保存在 skill 目录外，环境变量 `TIKTOK_LIBRARY_CONFIG` 指向其绝对路径。示例配置不含有效账号数据。

团队成员通过表格创建任务、填写关键词、选择数量和门槛后点击开始采集。只有指定执行机配置浏览器登录、飞书授权和网盘访问。保留当前授权身份；需要切换账号或机器人身份时先获得用户授权。

## 执行

```powershell
$env:TIKTOK_LIBRARY_CONFIG = 'D:\collector\collector.config.json'
python <skill目录>/scripts/run_feishu_tasks.py
# 持续轮询，运行窗口关闭后会停止；系统开机启动需另外配置
python <skill目录>/scripts/run_feishu_tasks.py --watch --interval 15
```

单次命令处理状态为“待采集”的任务；不要为测试将真实任务重新排队。启动前确认网盘存在、浏览器已登录和飞书身份可用。共享盘不可达时直接失败，不静默改成本地路径。

执行器从已授权浏览器搜索和滚动页面，读取会话捕获的搜索响应，按葡语、文案词匹配和播放点赞门槛过滤，综合两项排名下载。默认门槛播放 100000、点赞 1000；自定义的 0 表示该项不设下限。实际候选不足时返回“数量不足”，不降低门槛补数。

视频按 `日期/国家/关键词/视频ID/视频ID.mp4` 保存；日期使用 UTC+8。关键词目录只保留视频，运行数据放配置目录的 runtime。下载用 yt-dlp，随后 ffmpeg 完整解码、SHA256 校验共享盘副本并原子改名。播放量与点赞量是采集时快照，巴西地区仅由葡语及账号资料推断，不代表平台验证。

飞书素材按视频 ID 去重。附件上传结果不明确时先回查已有附件，避免盲目重试造成重复。单次任务故障写回状态和说明；不要打印 Cookie、完整网络响应或鉴权信息。

## 团队运行与故障

共享盘字节锁保证同一素材库串行处理；本机另有 worker/watch 锁。发现旧锁先确认原进程退出，再处理锁文件；不要直接删活跃锁。执行机崩溃后“采集中”的任务需人工确认文件和附件状态后再重新入队，当前版本不自动抢占过期任务。

登录过期、验证码、访问权限错误时停止相应任务，交给用户恢复登录。只采集用户有权访问及使用的素材，不绕过访问限制。首次部署先用一条小任务验证文件、附件和状态，再启用长期轮询。

下载器改为独立 yt-dlp 实现，无需复制外部下载 skill；部分 TikTok 链接可能失败。当前包离线验证通过不等于在任意新账号上完成端到端验证。修复下载问题时保持用户选定数据源与费用约束。
