# 部署与字段映射

## 依赖和配置

Windows、Python 3.11+（使用 hashlib.file_digest）、ffmpeg、yt-dlp、browser-act CLI、lark-cli。浏览器需由使用者登录 TikTok，飞书 CLI 需由有权限的使用者授权。browser-act 的 CLI 版本和响应格式可能变化，先运行本机帮助并做小样本验证；不要自动开启付费后端。

安装 Python 下载依赖：`python -m pip install yt-dlp`。其余 CLI 按各自官方安装说明安装，并验证 `browser-act --help`、`lark-cli --help`、`ffmpeg -version`。

在 skill 目录外建立工作目录，把 collector.config.example.json 复制为 collector.config.json。填写：

| 配置项 | 含义 |
|---|---|
| base_token | 目标 Base 的 token |
| tasks_table_id | 任务表 ID |
| assets_table_id | 素材表 ID |
| attachment_field_id | 素材表“视频”附件字段 ID |
| browser_id | 用户授权的本机 browser-act 浏览器 ID |
| media_root | 已存在且可写的素材库目录，支持 UNC；相对路径以配置目录为基准 |
| lark_cli | lark-cli 命令或其完整可执行路径 |

不要提交真实配置、Cookie、视频、日志、网络抓包或密钥。公共包不包含原公司的网盘路径、账号和表格 ID。

## 任务表

精确使用下列字段名称；执行器通过名称读写：

| 字段 | 类型/建议默认值 |
|---|---|
| 任务名称 | 文本主字段 |
| 关键词 | 文本，必填 |
| 国家 | 文本，巴西 |
| 采集数量 | 单选 10、20、50、100，默认20 |
| 门槛模式 | 单选 默认、自定义，默认默认 |
| 最低播放量 | 数字，100000 |
| 最低点赞量 | 数字，1000 |
| 状态 | 文本，未开始 |
| 已下载数量、已上传数量 | 数字 |
| 本地目录、运行说明、执行机、开始时间、结束时间 | 文本 |
| 开始采集 | 按钮 |
| 提交人 | 创建人，表示建记录者，不能当作按钮点击者 |

另建“目标数量”数字字段供历史兼容，默认20，可隐藏；当前 CLI 字段投影包含此字段。

## 素材表

文本主字段“视频ID”；文本字段“采集任务、关键词、国家、采集日期、作者、标题、来源链接、本地路径、地区依据、上传状态”；数字字段“播放量、点赞量”；附件字段“视频”。“采集任务”存任务 record_id 文本，不是关联字段。

## 按钮和自动化

为“开始采集”按钮绑定记录级自动化：关键词非空，且状态不属于“待采集、采集中、上传中”时，把当前记录状态改为“待采集”，运行说明改为“已提交，等待执行机”。其他情况不重复入队。可用飞书界面配置；如通过 CLI 创建，先读取目标版本 workflow schema 并使用实际字段 ID，不猜工作流结构。

按钮负责入队，不在飞书云端下载。执行机轮询队列，成员需有任务表编辑权限、素材表阅读及附件访问权限；执行身份需要两表读写和附件上传权限。不要为便利扩大到整个组织。多人同时提交会排队，正常情况下无需给每个成员配置密钥。

先保存并启用自动化，验证点击按钮能改状态，再启动单次 worker。长期值守请在指定机器配置 Windows 计划任务并使用有 SMB 和飞书权限的运行账号；本包不自动创建系统任务。网络盘在后台账号下的权限可能与交互登录不同，优先用 UNC 并在相同运行账号下验证。

## 验证和边界

运行 scripts/verify_package.py 可离线检查筛选、门槛和包内泄露。首次连接新环境仍需一条真实任务端到端验收。浏览器响应解析依赖 browser-act 的 CSV 请求列表及 response_body 行；格式变化时先调整适配。运行数据可能含敏感签名 URL，不放公共仓库。
